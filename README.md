# Juste Debout — App

> La plateforme mondiale de la Street Dance. 365 jours par an.

Application mobile (iOS + Android) construite avec **Expo / React Native**.

## Démarrage rapide

```bash
# Installer les dépendances
npm install

# Lancer sur le téléphone (Expo Go + QR code)
npx expo start

# Lancer dans le navigateur
npx expo start --web
```

## Ce que contient la V1

Un prototype complet et navigable des 13 piliers du produit : événement,
profils, statistiques, réseau mondial, marketplace, replay, formations,
masterclass, job board, passeport, hall of fame, gamification, et l'assistant
IA « JD Companion ». Les données sont des données de démonstration
(`src/data/mock.ts`).
